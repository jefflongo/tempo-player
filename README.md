# Tempo Player

A simple command-line audio player designed to help with instrument practice. It allows playback from audio files or YouTube. Additionally tempo adjustment, start/end cropping, and looping is supported.

## Install

This application will not be available on until [crates.io](https://crates.io/) until [yt-dlp video searching](https://github.com/boul2gom/yt-dlp/issues/314) is fixed. Until then, install locally:
```bash
cargo install --path .
```

## Usage

```bash
tempo-player <path, query, or URL> <options>
```
